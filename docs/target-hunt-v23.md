# CHASE CITY — TARGET HUNT + 파괴 폴리시 (V2.3 작업분)

브랜치 `claude/v20-mission-platform` · main 병합 안 함 · 기존 미션·조작 변경 없음.

## 1. 새 미션: 타깃 헌트 (TARGET HUNT)
- 플레이어가 사냥꾼: 도망치는 노란 타깃 차량을 들이받아 파괴. 경찰 없음, 시간 제한 없음, 기존 도시 맵.
- 타깃 AI (`src/game/target.js`): 도로를 교차로 단위로 주행, 플레이어에게서 멀어지는 길·최근 지나간 교차로를 피하는 길 선택 + 가끔 페이크(예측 불가), 코너에서 감속하며 부드럽게 회전, 직선 19 m/s(플레이어 24), 게임 충돌 처리 그대로 사용(건물·장애물 통과 불가), 막힌 길은 일정 시간 회피하고 경로 따라 복귀. 순간이동·급가속 없음.
- 피해: 실제 차체 접촉만, 충돌 속도에 비례(후미 추돌 약 5–12, 측면 강타 최대 34, 한 번 밀기 = 1회). 맞으면 잠깐 가속해 도망.
- 0이 되면 전복·폭발, 불타는 잔해 유지, 1.6초 후 미션 성공. 재시도 시 새 타깃.
- 화면: 노란 차 + 검은 줄무늬, 빨간 마커·바닥 링, 손상 연기, 피격 섬광·카메라 흔들림, 미션 카드 아래 내구도 바, 화면 밖이면 방향 화살표+거리.
- 측정(`scripts/hunt-eval.mjs`, 8 시드, 기본·미리보기 맵): 타깃 단독 2분 — 장애물 내부 0, 순간이동 0, 정지 0, 반복 루프 0, 교차로 평균 28곳 / 좌우 키만 쓰는 추격 봇 — 16/16 격파, 첫 충돌 약 7초, 중간값 48–60초(19–135초).

## 2. 시장 가판대 파괴
- 가판대는 미리 쪼갠 조각: 맞으면 차양(가볍게 멀리 날며 회전), 테이블(무겁게 넘어짐), 간판, 기둥 4개, 농산물 상자 3개가 충돌 방향으로 날아가고 과일이 쏟아짐 — 제자리에서 납작해지지 않음.
- 파라솔은 가벼워져 기울고 회전하며 날아가고, 세게 맞으면 천과 기둥이 분리. 테이블은 더 쉽게 부서지고, 상자·기둥은 두 번 튕김. 모두 미션 끝까지 유지.

## 3. 노란 오버헤드 구조물 (MARKET 아치) + DEPOT 게이트
- 기둥을 세게(접근 속도 8 m/s 이상) 치면: 그 기둥이 부러져 넘어지고 반대 기둥은 휘며, 보가 부러진 쪽부터 내려앉은 뒤 무게감 있게 회전하며 떨어짐(스크립트 키프레임). 약하면 흔들리기만.
- 쓰러진 기둥은 충돌 판정 제거, 보는 항상 도로 반대쪽으로 쓰러지고 차가 그 자리에 없을 때만 충돌체가 됨 → 갇힘 없음. DEPOT 게이트도 같은 방식.

## 4. 가스 저장소 (새 대형 폭발 장소, 블록 −45, 45)
- 다리 위 구형 LPG 탱크(사다리·상부 난간), 받침대 위 원통형 탱크 2기, 고가 배관 랙·밸브, 가스통 철장, 관리 초소, 안전 줄무늬 바닥, 철망 펜스(출입구 2곳).
- 탱크를 세게 들이받거나 근처에서 폭발이 나면 대형 폭발(게임 최대 규모) → 나머지 탱크 연쇄 폭발. 구형 탱크 껍데기 조각·원통 반쪽이 날아가 저장소 안에 떨어지고, 다리 휘고, 받침 찌그러지고, 배관 랙 붕괴, 가스통·펜스 날아감, 불 계속 탐, 잔해 유지. 경찰 근처는 대파, 플레이어·타깃도 피해. 연기는 차량 가림 시 투명 처리 적용.
- 생존 모드에서도 동일하게 작동(공유 맵).

## 검증
- 유닛 테스트 166개 통과(타깃 헌트 4, 가스 저장소 3 추가).
- 브라우저 회귀 테스트 20/20 통과(생존 모드, 미션 선택 3개, 핀 체포, 도시 상호작용 등).
- 미리보기 장애물 갇힘 검사 163회 중 0회 갇힘.
- 경찰 체포 감사(미리보기, 24회): 오체포 1건(코트 근처, 우→좌 복합 조작으로만 탈출 가능한 경계 사례), 정지한 경찰 1대.
- 성능(iPhone 13 에뮬레이션·SwiftShader, 상대값): 타깃 헌트 평상시 250 ms/87 콜, 가스 저장소 연쇄 + 시장 파괴 후 170–200 ms/69–96 콜.
