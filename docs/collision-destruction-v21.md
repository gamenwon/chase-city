# CHASE CITY — 충돌 버그 수정 · 파괴 연출 보강 (V2.1 작업분)

브랜치 `claude/v20-mission-platform` · main 병합 안 함 · CITY ESCAPE 미션은 구현하지 않음.

## P1 갇힘 · 체포 · 카메라 흔들림
- 원인 1: 큰 나무·가로등 같은 소품이 벽 미끄러짐(슬라이드) 처리에서 빠져 있어, 자동 전진 차량이 정면으로 계속 다시 부딪힘 → 영구 갇힘 + 매 프레임 충돌.
  수정: 서 있는 기둥·나무를 벽처럼 취급, 옆으로 돌아 나가는 방향을 정해 그 방향을 끝까지 유지.
- 원인 2: 벽에 붙어 미끄러지는 동안 차 머리가 벽을 향한 채 옆으로만 움직임(짧은 포켓에서 왕복).
  수정: 미끄러지는 방향으로 차 머리를 돌림, 왕복이 반복되면 벽 반대쪽으로, 1.2초 이상 제자리면 가장 열린 방향으로 회전.
- 미리보기 맵 모서리 광고판 다리 뒤 빈틈(차가 끼면 못 나옴)을 막음.
- 카메라 흔들림: 같은 소품에 계속 닿아 있는 동안에는 충격 이벤트·데미지·흔들림 없음(새 충돌만). 갇힌 상태에서 차가 좌우로 떨던 것도 제거.
- 경찰: 잔해에 갇혀 6초 이상 못 움직이면 화면 밖에서 재투입. 미끄러짐 계산에 경찰차도 장애물로 포함.
- 체포: 경찰 잔해 2대 이상에 둘러싸이고 경찰이 현장에 있으면 포위로 인정 / 벽+경찰 1대로 막힌 경우 3.5초 정지 후 인정 /
  기존 기하학적 포위 판정도 실제 물리 탈출 시뮬레이션이 "탈출 불가"를 확인해야 체포. 나무·벽만으로는 절대 체포 안 함.

## P2 폭발
`src/render/explosions.js` 전면 교체: 흰-노란 섬광 → 주황·빨강 화염 → 검은 그을음, 불씨, 충격파 링+먼지 링, 위·바깥으로 튀는 파편(착지 후 유지),
오래 피어오르는 각진 검은 연기 기둥(차 14초 · 주유소 45초 · 대형 70초). 크기: 차 1.4 / 주유소 2.6 / 대형 3.4, 카메라 충격도 크기 비례.
모든 입자는 인스턴스 풀(폭발 수와 관계없이 고정 드로우콜).

## P3 주유소 붕괴
캐노피를 6개 슬래브 + 기둥 4개로 미리 분할(단면에 철근·깨진 콘크리트). 펌프섬 하나 폭발 → 해당 기둥 꺾임, 위 슬래브가 펌프 위로 낙하, 다른 줄 처짐.
두 섬 모두 → 캐노피 전체 붕괴 + 대형 폭발. 매장 간판 떨어져 매달림, 매장 전면 그을음, 파라펫 일부 붕괴, 유리·조명판·간판 조각 산재, 잔해 위 불 지속.
붕괴된 캐노피는 차가 그 안에 없을 때만 충돌체가 됨(끼임 방지).

## P4 1층 상점
모든 도로변 상점(208곳) 파괴 가능, 1/4은 강한 충돌 시 화재. 모든 상점에 줄무늬 차양 추가 → 충돌 시 차양 찢어져 내려앉음, 간판 매달림/바닥에 떨어짐,
유리·창틀·진열대·물건이 인도까지 흩어짐. 건물 자체는 무너지지 않음. **현재 미리보기(장소 미리보기)에만 적용 — 본 게임 반영은 승인 후.**

## P5 타이어 소리
톱니파 발진기 2개(전자음) → 고무 stick-slip 모델: 노이즈가 좁은 공진 3개(1.0/2.13/3.37배)를 울리고, 음높이 무작위 흔들림 + 불규칙 떨림 + 고무 마찰음.
반복 루프 없음, 발진기 없음, 같은 조건에서만 발생, 시작 0.06초 / 끝 0.22초. 외부 음원은 사용하지 않음(라이선스 확인 불필요).
