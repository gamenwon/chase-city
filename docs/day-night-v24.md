# CHASE CITY — 낮 / 밤 시스템 (V2.4 작업분)

브랜치 `claude/v20-mission-platform` · main 병합 안 함 · 새 미션·맵·파괴·경찰 변경 없음.

## 동작
- 매 판(시작·재시작·미션 변경)마다 낮/밤을 50:50으로 무작위 선택, 그 판 동안 고정.
- 선택은 `Math.random` 사용 — 게임의 시드 난수와 분리돼 게임 진행은 낮/밤 상관없이 완전히 동일(테스트로 확인).
- 테스트용 고정: `?tod=day` / `?tod=night` (본 게임은 개발 빌드에서만, 미리보기 테스트 페이지는 항상).

## 낮
- 기존 밝고 화사한 화면 그대로.

## 밤
- 짙은 파란 하늘·안개, 푸른 달빛과 보조광으로 도로·건물·차량·장애물이 잘 보이게 유지, 노출 소폭 상향.
- 가벼운 야간 조명(동적 광원 없이 인스턴스 메시 몇 개, 밤에만 그림, `src/render/night.js`):
  - 서 있는 모든 가로등·공원등 아래 따뜻한 빛 웅덩이 + 전구 발광 + 후광.
  - 상점 1층 쇼윈도 전부 점등, 위층 창문은 일부만 점등(건물이 카메라 때문에 투명해지면 창문도 함께 숨김).
  - 플레이어·경찰·타깃·일반 차량에 전조등 빛줄기와 전조등·후미등.
  - 간판은 자기 그림을 발광 텍스처로 사용해 빛남, 경찰 경광등·가로등 머리는 더 밝게.
- 폭발·불꽃은 조명을 받지 않는 재질이라 밤에 더 선명, 폭발 순간 거리 전체가 잠깐 밝아짐.

## 검증
- 유닛 테스트 170개 통과(낮/밤 4개 추가: 50:50 선택·판 중 고정·미션 변경 시 재선택 / 고정 옵션 / 낮·밤 게임 진행 동일 / 창문 위치).
- 실제 페이지에서 재시작 8회: 밤·밤·낮·낮·밤·낮·밤·밤, 렌더러가 매번 따라감.
- 휴대폰(iPhone 13 에뮬레이션)·데스크톱, 본 게임·미리보기 모두 낮/밤 스크린샷 비교, 밤 폭발 확인.
- 성능(SwiftShader 상대값): 밤이 드로우콜 +7, 삼각형 +6.5천, 프레임 약 +5~10% (소프트웨어 렌더링의 가산 합성 비용 포함, 실제 GPU에서는 더 작을 것으로 예상).
