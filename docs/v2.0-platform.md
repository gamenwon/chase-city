# CHASE CITY V2.0 상용화 기반 구조

V2.0은 경찰 추격전 하나였던 게임을 **여러 미션을 담는 캐주얼 3D 자동차 미션 게임**으로 바꾸기 위한 기반입니다. 경찰 추격전은 첫 번째 미션으로 확정된 것이 아니라 등록된 미션 중 하나입니다.

## 구성 한눈에 보기

| 파일 | 역할 |
|---|---|
| `src/game/missions.js` | 미션 정의(목표·제한 시간·성공/실패 조건·보상·맵·규칙)와 공통 판정 |
| `src/game/catalog.js` | 미션 노출 순서(설정값) |
| `src/game/tally.js` | 결과 화면의 파괴 기록(실제 이벤트 기준, 물체당 1회) |
| `src/game/vehicles.js` | 차량별 성능(속도·조향·접지·내구)과 해금 정보 |
| `src/game/progress.js` | 게임 내 재화(크레딧)·미션 기록 저장 |
| `src/platform/ads.js` | 회사 광고 시스템을 연결하는 지점(보상형 광고) |
| `src/world/maps.js` | 맵 등록(지형·오브젝트·색상) |
| `src/render/pickups.js` | 수집형 미션 아이템 표시 |
| `art-sample.html`, `src/art/sample.js` | 아트 비교 샘플(게임과 별도 페이지) |

## 미션 추가 방법

`src/game/missions.js`의 `MISSIONS`에 항목을 하나 추가합니다.

```js
myMission: Object.freeze({
  id: "myMission",
  type: "carry",            // chase, collect, carry, stealth, evade ...
  title: "화물 운반",
  objective: "...",
  mapId: "downtown",        // world/maps.js에 ready: true인 맵
  durationClass: "short",   // short 30-90초 / challenge 2-3분
  timeLimit: 90,            // 초, 없으면 null
  target: 3,
  reward: { type: "credits", amount: 400 },
  rules: { police: false }, // 경찰(추격·포위·바리케이드·증원) 사용 여부
  failOn: ["destroyed", "timeout"],
  continueOn: ["destroyed", "timeout"], // 광고 이어하기 허용 실패
  progressLabel: "운반", unit: "개",
  progress: (sim) => ...,   // 현재 진행 수치
  setup(sim) { ... },       // 시작 전 배치(선택)
  update(sim) { ... },      // 매 스텝 판정, 성공이면 completeMission(sim)
  hud: (sim) => "...",      // 화면 상단 미션 카드 문구
}),
```

- 실패 판정은 공통입니다: 차량 파괴(`destroyed`), 체포(`arrested`, 경찰이 있는 미션), 시간 초과(`timeout`, `timeLimit`이 있을 때).
- 보상은 `completeMission(sim)`이 한 번만 지급합니다.
- 노출 순서에 넣으려면 `catalog.js`의 `DEFAULT_MISSION_ORDER`에 id를 추가합니다.

## 미션 노출 순서 바꾸기 (코드 수정 없이)

게임 스크립트보다 먼저 아래 설정을 넣으면 순서가 바뀝니다. 목록에 없는 미션은 숨겨집니다.

```html
<script>
  window.CHASE_CITY_CONFIG = { missionOrder: ["parcels", "survival60"] };
</script>
```

## 결과 화면의 파괴 기록

- 도시 이벤트가 발생하는 순간 `sim.onCityEvent`로 바로 집계합니다(화면 효과용 이벤트 목록은 64개로 잘리므로 쓰지 않습니다).
- **플레이어가 부순 것만** 셉니다. 경찰차가 넘어뜨린 표지판은 세지 않습니다.
- 플레이어가 밀어 보낸 차가 2초 안에 다른 차를 부수면 플레이어 기록입니다.
- `종류:물체 ID`로 한 번만 셉니다. 쓰러진 쓰레기통을 다시 차거나, 부서진 차가 다시 시야에 들어와도 중복되지 않습니다.
- 표시 예: 쓰레기통 3개 · 표지판 1개 · 가로등 1개 · 가로수 1그루 · 일반 차량 2대

## 광고 연결 (회사 기존 광고 시스템 재사용)

게임은 광고 SDK를 포함하지 않으며 **광고를 본 것처럼 처리하지 않습니다.** 광고 모듈이 등록되기 전에는:

- 배포 빌드: 광고 버튼이 보이지 않습니다. 다시 도전·다음 미션·미션 선택은 그대로 동작합니다.
- 개발 빌드(또는 `?adtest`): 버튼이 "광고 미연동"으로 **비활성** 표시됩니다(배치 확인용).

연결 방법: 회사 광고 모듈이 아래 형태의 객체를 등록합니다.

```js
window.ChaseCityAds.register({
  isReady(placement) { return true; /* 광고 준비 여부 */ },
  async showRewarded(placement) {
    // 실제 SDK 호출 후, SDK가 보상 지급 조건 충족을 알려줄 때만 true
    return { rewarded: true };
  },
});
// 또는 게임 로드 전에 window.CHASE_CITY_AD_PROVIDER = { ... }
```

| 배치(placement) | 언제 | 보상 |
|---|---|---|
| `mission_fail_continue` | 실패 결과 화면 | 그 판을 이어서 1회 진행(차량 파괴 → 내구도 60%, 체포 → 주변 경찰 철수와 6초간 포위·봉쇄 금지, 시간 초과 → 20초 추가) |
| `mission_success_double` | 성공 결과 화면 | 미션 보상만큼 크레딧 추가 1회 |

`rewarded`가 정확히 `true`일 때만 보상합니다. 오류·중간 닫기·`false`는 보상이 없습니다.

## 게임 내 재화와 포인트앱 포인트

- 게임 안의 재화는 **크레딧**이며, 브라우저 저장소(`chase-city-progress`, 버전 1)에 보관합니다.
- **포인트앱 지급 포인트와 완전히 분리**되어 있습니다. 크레딧을 포인트로 바꾸거나 포인트를 지급하는 코드는 없습니다. 포인트 지급이 필요하면 서버에서 검증하는 별도 경로로 만들어야 합니다(브라우저 저장값은 사용자가 바꿀 수 있습니다).
- 같은 판의 보상은 한 번만 지급됩니다(판 번호 + 지급 종류로 중복 방지).
- 일일 보상, 반복 플레이 강요 기능은 넣지 않았습니다.

## 차량 성장 구조

`src/game/vehicles.js`

- `stats`: `topSpeed`(m/s), `turnRate`(rad/s), `grip`(1/s), `durability`(100 기준, 받는 피해 = 원래 피해 × 100 / 내구)
- `unlock`: `{ type: "starter" }` 또는 `{ type: "credits", cost }`
- 기본 차량 `starter`는 V1.9 수치와 똑같아 난이도가 변하지 않습니다.
- `boxy`(박스 미니)는 해금 구조 확인용 데이터이며 아직 선택할 수 없습니다(해금 화면 없음). 아트 샘플의 박스형 차량이 이 차의 외형 후보입니다.
- 저장 데이터에 `vehicles.owned`, `vehicles.selected`가 있어 해금·수집 화면을 붙일 수 있습니다.

## 맵 추가 방법

`src/world/maps.js`

- 맵 항목: `id`, `name`, `label`, `createLayout()`(건물·공원·고정 장애물), `city`(행인·차량·시설물), `theme`(하늘·안개·잔디·보도·도로·차선 색), `ready`.
- 도심(`downtown`)만 만들어져 있고, 항구·산악·교외는 `ready: false`로 등록만 되어 있습니다.
- 차량 조작·카메라·충돌·경찰·도시 시스템은 모든 맵이 함께 씁니다.
- 새 맵을 만들 때 할 일: `createLayout()`과 `theme` 작성 → 렌더러 지면 그리기(`src/render/scene.js` 생성자의 도로 격자)를 맵 데이터로 옮기기 → 미션의 `mapId` 지정. 지금 렌더러는 도로 격자(30 m 간격)를 직접 그리므로, 격자가 다른 맵은 이 부분을 맵 데이터에서 읽도록 바꿔야 합니다.
- 현재 한 페이지에서 렌더러는 시작 맵으로 한 번 만들어집니다. 다른 맵 미션으로 바꿀 때 렌더러를 다시 만드는 처리는 두 번째 맵을 만들 때 추가해야 합니다.

## 아트 샘플

`art-sample.html` (빌드 시 별도 페이지). 현재 그래픽과 파스텔 로우폴리 제안을 나란히 보여 줍니다.

- 차량 1종: 짧고 높은 둥근 박스형 차체, 큰 바퀴와 흰 휠, 둥근 전조등.
- 소규모 환경: 줄무늬 차양과 간판이 있는 상점 2채, 박공지붕 주택 2채(굴뚝·화단·울타리), 둥근 로우폴리 나무, 가로등·벤치·쓰레기통, 횡단보도.
- 부드러운 그림자(VSM)와 따뜻한 조명, ACES 톤 매핑.
- 게임 화면은 바뀌지 않았습니다. 확정되면 같은 스타일을 도시 전체·다른 맵에 적용합니다.
