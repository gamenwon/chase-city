# CHASE CITY — 최종 폴리시 (V2.2 작업분)

브랜치 `claude/v20-mission-platform` · main 병합 안 함 · 미션·조작·무관한 게임플레이 변경 없음.

## 1. 폭발 연기 투명 처리
- 건물 투명 처리와 같은 원리: 연기 기둥이 카메라와 플레이어(또는 45 m 안의 경찰차) 사이를 가리면 그 기둥만 반투명(퍼프당 10%)으로, 벗어나면 다시 진하게.
- 퍼프마다가 아니라 **기둥마다 1회** 검사(바람에 기우는 원기둥 + 초기 먼지 링) → 비용 = 기둥 수 × 차량 수.
- 부드러운 전환(지수 감쇠, 깜빡임 없음). 안 가리는 연기는 그대로 불투명·검정. 폭발 연출은 그대로.
- 근거: `docs/evidence/polish-v22/smoke-seethrough-off-on.png` (왼쪽 끔 / 오른쪽 켬).

## 2. 타이어 스키드 소리 — 보류
요청에 따라 보류 과제로 남김(자세한 사유: `docs/audio-assets.md`). 기존 소리는 손대지 않음.

## 3. 타이어 자국
- 빠른 속도의 급회전(스크리치와 같은 조건)에서만 뒷바퀴 두 개 위치에 자국 생성, 연속 점을 이어 곡선으로. 미끄러질수록 진하게.
- 도로 위 0.135 m + polygon offset(겹침 깜빡임 없음), 미션 끝(재시작)까지 유지.
- 예산 6,000 조각(링 버퍼: 가장 오래된 것만 재사용, 최근 자국은 사라지지 않음), 8개 청크로 나눠 화면 밖 구간은 그리지 않음. 기존 4초짜리 자국 64개(드로우콜 64)를 대체.

## 4. 배경음악
- "Getaway Club" — 이 프로젝트용 오리지널 곡, 150 BPM 일렉트로닉 록, 보컬 없음, 76.8초 끊김 없는 루프.
- `scripts/music/compose.mjs`가 드럼·베이스·리듬 신스·리드·아르페지오를 작곡·합성(샘플·외부 음원 없음) → `public/audio/chase-city-bgm.mp3`.
- 첫 사용자 입력(START) 후에만 로드(자동재생 정책 준수), 정확한 루프 지점, 음소거에 따름, 일시정지·메뉴에서 작게, 폭발 시 잠깐 낮춤, 엔진보다 약 4 dB 아래.

## 검증
- 유닛 테스트 159개 통과(연기 투명 1, 타이어 자국 2, 음악 1 추가).
- 브라우저 테스트 20개 중 18개 첫 실행 통과, 실패 2개(미션 선택·광고 보상)는 단독 재실행 시 7/7 통과 → 병렬 부하 타이밍 문제.
- 실제 플레이: 키보드 좌우로 22초 운전하며 자국 확인, 폭발 연기 뒤 플레이어·경찰차 투명 확인, 휴대폰 에뮬레이션에서 탭 시작·터치 조향·음악 재생·음소거 확인.
- 성능(iPhone 13 에뮬레이션·SwiftShader, 상대값): 평상시 257 ms/110 콜 → 폭발 4회 반복 + 자국 6,000개 후 320 ms/305 콜. 자국 비용 약 19 ms(화면 안 구간만).
