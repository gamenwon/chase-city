# CHASE CITY 아트 디렉션 개정안 (각진 로우폴리 도시 지구, 승인용)

이전 시안(`art-direction.html`, `docs/art-direction-v2.md`)은 의도한 방향과 맞지 않아 이 문서로 대체합니다. 기준 레퍼런스는 새로 받은 두 장입니다(레퍼런스 A: 빨간·파란 건물과 농구장, 레퍼런스 B: 주황 아파트와 교차로).

- 미리보기: `art-district.html` (`src/art/district.js`). 게임과 별도 페이지이며 게임 화면은 바뀌지 않았습니다.
- 실행: `npm run dev` 후 `/art-district.html`, 또는 배포 링크.

## 2. 지구 구성 (한 장소처럼 연결된 지구)

4차선 대로(동서)와 2차선 도로(남북)가 만나는 교차로를 중심으로 네 블록이 있습니다. 신호등, 횡단보도, 정지선, 중앙 노란 이중선, 차선, 가로등, 화분 울타리, 재활용 쓰레기통, 소화전, 정지 표지판도 있습니다.

| 블록 | 장소 | 주요 디테일 |
|---|---|---|
| 북서 | **상점가** | 빵집(박공지붕)·피자(평지붕)·서점(3층, 발코니)이 이어진 상점가, 테라스 카페(파라솔·테이블·의자), 과일 노점, 뒤편 6층 주황 아파트(발코니·회전문 입구·물탱크) |
| 북동 | **주유소** | 캐노피와 기둥 4개, 주유기 섬 2개(주유기 4대), 주유 중인 픽업트럭, 24시 편의점, 가격 기둥 간판, 옆에 옥상 광고판이 있는 빨간 4층 건물 |
| 남서 | **공원** | 8각 분수, 대각선 산책로, 벤치, 각진 나무, 가로등, 그네, 나무 울타리 |
| 남동 | **농구장·주거** | 철망 펜스 농구장(골대 2개, 공, 벤치), 태양광 패널 파란 주거 건물, 줄무늬 차양 모서리 카페, 박공지붕 주택 2채 |
| 도로 위 | **추격** | 플레이어 차(자홍색 머슬카), 경찰차 2대(대로 추격, 남북 도로 진입), 택시·청록 세단·밴·주황 세단 |

플레이어 차는 팔레트에서 하나뿐인 **자홍색 `#e0367a`**에 흰 레이싱 줄, 긴 보닛, 스포일러를 달아 어디서든 바로 보이게 했습니다. 경찰차는 검정·흰색에 경광등과 범퍼 가드를 달았습니다.

## 3. 파괴 디자인

모든 파괴 결과는 미션이 끝날 때까지 남는 잔해로 설계했습니다. 표현은 만화풍이고 사람 부상 표현은 없습니다.

| 대상 | 파괴 후 | 연출 |
|---|---|---|
| 주유소 | 캐노피가 한쪽으로 주저앉음, 기둥 휨, 주유기가 날아감, 그을음 자국, 불길 5곳과 연기 기둥, 픽업이 뒤집힘, **들어오던 경찰차가 뒤집혀 그을림**, 편의점 유리 깨짐 | 각진 불덩이 + 충격파 고리 + 파편 비행(가장 큰 폭발) |
| 농구장 | 도로 쪽 펜스가 쓰러지고 반대편은 기울어짐, 골대가 꺾여 넘어짐, 공 12개 흩어짐, 벤치 뒤집힘 | 먼지 구름 + 파편 |
| 분수 | 수반이 조각나고 기둥이 쓰러짐, 거대한 물기둥과 물보라, 물웅덩이 | 물보라 폭발 |
| 카페·노점 | 차양 찢어짐(반은 매달리고 반은 바닥), 테이블 뒤집힘, 파라솔·의자 흩어짐, 유리 파편, 노점 상자 부서지고 과일 굴러감 | 먼지 구름 + 파편 |
| 가로수·가로등·표지판·울타리 | 나무가 보도에 쓰러짐, 가로등 꺾임, 표지판 납작, 울타리 살이 흩어짐 | 먼지 구름 + 파편 |

미리보기에서는 `파괴 전 / 파괴 후` 버튼으로 전체 상태를 바꾸고, `파괴 재생`으로 순서대로 터지는 연출을 봅니다. 순서는 소품 → 노점 → 카페 → 농구장 → 분수 → 주유소입니다.

**형태 규칙**
- 상자·사다리꼴·삼각기둥·6–8각 기둥·20면체만 씁니다. 모서리를 둥글리지 않고, 모든 재질을 평면 셰이딩합니다.
- 건물은 높이, 지붕 형태, 1층 용도(상점·입구·카페)를 블록마다 다르게 합니다.
- 창은 반드시 틀·창턱과 함께 넣고, 2–3층마다 층 띠를 둡니다. 옥상에는 파라펫과 설비를 올립니다.
- 차량은 길이 3.8–4.4 m, 폭 1.9–2.0 m입니다. 게임 충돌 상자(2.1 × 3.6 m)에 맞추려면 적용 시 길이를 약 8% 줄입니다.
- 주요 충돌 물체(주유기, 기둥, 나무, 가로등, 펜스)는 게임 카메라 높이에서 실루엣이 분명하도록 굵기 0.1 m 이상, 높이 0.7 m 이상으로 합니다.

**빛과 그림자**
- 따뜻한 직사광(왼쪽 위)과 선명한 그림자(PCF soft, 그림자맵 4096)를 씁니다. 휴대폰에서는 2048로 낮춥니다.
- 반구광은 하늘 `#fff6ee`, 땅 `#7a5c84`로 해서 그늘을 보랏빛으로 만듭니다.
- 톤 매핑은 ACES를 씁니다.

## 5. 성능 (모바일 우선)

- 정적인 모든 것(도로·보도·건물·가구)을 **재질별로 합쳐서** 그립니다. 같은 부품을 재사용하는 모듈 키트(파사드, 차양, 가로등, 쓰레기통 등)로 만들었습니다.
- 미리보기에서 측정한 그리기 호출은 화면에 따라 약 80–410회, 삼각형은 2만–3만 개입니다. 많은 쪽은 차량(경광등 깜빡임 때문에 따로 그림)과 간판 텍스처 때문입니다. 게임에서는 차량을 인스턴싱하고 간판을 아틀라스 하나로 묶으면 더 줄일 수 있습니다.
- 잔해는 정지한 정적 메시로 남깁니다. 날아가는 연출에만 짧은 트윈을 쓰고, 계속 도는 물리 시뮬레이션은 없습니다.
- 소프트웨어 렌더링 환경이라 실제 휴대폰의 FPS는 재지 못했습니다.

### 차량 (레퍼런스 7 기준)
공통 부품으로 실제 차 구조를 만듭니다(`chassis`, `cabin`, `doorsAndMirrors`, `ends`).
- **차체·바퀴:** 바퀴 아치(어두운 휠 하우스와 펜더 립), 타이어·휠 림·허브, 사이드 스커트
- **캐빈:** A·B·C 필러, 지붕, 앞 유리(위쪽 틀)·뒤 유리·옆 유리 4장, 카울 라인
- **문:** 문 틈, 손잡이, 사이드미러(암과 하우징)
- **앞뒤:** 앞뒤 범퍼, 그릴과 크롬 살, 전조등(하우징과 렌즈), 방향지시등, 후미등, 번호판

부품은 서로 뚫고 들어가지 않게 간격을 두었습니다. 문 틈은 차체에서 0.01–0.03 m, 데칼은 그 바깥이나 안쪽 층에 둡니다. 경찰차는 경광등을 깜빡이므로 합치지 않고 따로 그립니다(게임에서는 차종별로 인스턴싱합니다).

### 건물 (레퍼런스 8 기준)
- **창 키트 개정:** 프레임이 벽에서 0.22 m 나오고 유리는 그 안쪽에 있어 실제 창처럼 오목하게 보입니다. 세로 살, 가로 살, 윗인방, 창턱을 갖췄습니다. 발코니·난간은 창턱 아래에 겹치지 않게 놓았고, 파라펫 모서리 겹침도 없앴습니다.
- **랜드마크: 모서리 와인 가게** (남동 블록 모서리, `랜드마크` 시점)

### 성능
랜드마크(벽돌 텍스처)와 차량은 따로 그리고, 나머지 정적 물체는 합쳐서 그립니다. 시점에 따라 그리기 호출은 약 100–430회, 삼각형은 3.7만–5.3만 개입니다. 게임에 넣을 때는 다음을 지킵니다.
- 랜드마크급 디테일은 주요 건물 몇 채에만 씁니다.
- 일반 건물은 창 키트만 씁니다.
- 차량은 차종별로 인스턴싱합니다.
