# CHASE CITY V2.0

Three.js HTML5 캐주얼 3D 자동차 미션 게임. **모바일 웹게임이 기본 플랫폼**이고(세로 화면·터치 조작 우선), PC는 보조 플랫폼입니다. V2.0은 포인트앱 서비스용 상용화 기반으로 **여러 미션을 담는 구조**를 만들었습니다. 경찰 추격전(포위·체포·충돌·폭발·PIP)과 V1.9 도시 상호작용은 그대로 유지되며, 경찰 추격전은 미션 중 하나입니다.

## V2.0 상용화 기반 (브랜치 `claude/v20-mission-platform`)

- **공통 미션 시스템:** 미션마다 목표·제한 시간·성공/실패 조건·보상·맵·사용 시스템(경찰 등)을 데이터로 정의합니다. 등록된 미션은 경찰 추격전 `도시 탈출`(60초 생존 후 탈출 게이트)과 수집형 `택배 수거`(경찰 없음, 80초 안에 택배 5개)입니다. 노출 순서는 설정값(`window.CHASE_CITY_CONFIG.missionOrder`)으로 바꿉니다.
- **미션 선택 화면:** 브리핑 카드의 `미션 선택`에서 목록(유형·맵·제한 시간·보상·기록)을 보고 고릅니다. 마지막에 고른 미션이 다음 접속 때 먼저 나옵니다.
- **결과 화면:** 결과와 플레이 시간, 플레이어가 파괴한 물체 종류별 개수(실제 이벤트 기준, 물체당 1회), 획득 크레딧, `다시 도전 / 다음 미션 / 미션 선택`.
- **광고 연결 지점:** 실패 시 광고 보고 1회 이어하기, 성공 시 광고 보고 보상 2배. 회사 광고 모듈을 `window.ChaseCityAds.register()`로 연결하기 전에는 비활성(배포 빌드에서는 숨김)이며, 광고를 본 것처럼 처리하지 않습니다.
- **재화와 차량:** 게임 내 재화 `크레딧`을 저장합니다(포인트앱 포인트와 분리). 차량별 속도·조향·내구 데이터 구조와 해금 정보(기본 차량은 기존 수치 그대로).
- **다중 맵 구조:** 맵별 지형·오브젝트·색상을 등록하는 구조. 도심만 제작, 항구·산악·교외는 등록만 했습니다.
- **아트:** 승인된 각진 로우폴리·선명한 색 방향을 게임에 적용했습니다(건물·차량·도로·공원·소품·폭발, `src/render/kit.js`). 시안은 `art-district.html`, 설명은 `docs/art-direction-v3.md` 9절에 있습니다.
- **체포 판정 수정:** 경찰차에 막혀 실제로 움직이지 못하는데(속도계는 숫자가 나와도) 체포되지 않던 문제를 고쳤습니다. 실제 위치 변화와 실제 주행 물리로 돌린 탈출 시험으로 "경찰차에 갇힘"을 판정하고, 화면에 `체포까지 3·2·1`을 표시합니다. 탈출하면 즉시 취소되고, 벽·장애물에만 걸린 경우는 체포하지 않습니다(`src/game/pin.js`).
- **수정:** 쓰러진 가로수가 차 위로 넘어지면 차가 장애물 안에 갇혀 영영 움직이지 못하던 문제(V1.9부터)를 고쳤습니다.

구조와 확장 방법은 [docs/v2.0-platform.md](docs/v2.0-platform.md), 검증 결과는 [TESTING.md](TESTING.md)의 V2.0 섹션에 있습니다.

> 실제 iOS Safari·실제 휴대폰에서는 테스트하지 못했습니다(Chromium의 iPhone 13 화면 흉내, GPU 없음).

## V1.9 도시 상호작용 (브랜치 `claude/v19-city-interaction`)

- **부서지는 거리 시설물 (`src/game/city.js`):** 모든 인도에 쓰레기통·표지판·가로등·가로수, 공원에 큰 나무(약 600개). 충돌 속도와 크기에 따라 반응이 다르다: 쓰레기통은 2.5 m/s만 넘어도 날아가며 쓰레기가 흩어지고, 표지판 6, 가로등 9, 가로수 11 m/s 이상이면 쓰러진다(그 아래에서는 기둥처럼 차를 막고 흔들린다). 큰 나무는 부서지지 않고 부딪힌 차에 피해를 준다. 부서진 시설물은 사라지지 않고 그 자리에 남는다. 쓰러진 가로수는 실제 장애물이 되어 경찰이 길을 돌아간다(건물 쪽으로 넘어질 때는 인도를 따라 넘어져 보이게 한다).
- **행인:** 인도를 따라 걷고 횡단보도로 길을 건넌다. 사람마다 걷는 속도·반응 시간(0.12–0.62초)·달리는 속도가 다르다. 플레이어·경찰차·일반 차량이 다가오면 놀라 옆으로 뛰어 피하고, 아주 가까우면 바로 몸을 날린다. 치는 게임이 아니라 피하는 게임이다(차가 사람을 통과하지 않는다).
- **일반 차량:** 주행 차량은 차선을 따라 달리고 교차로에서 직진·좌회전·우회전한다. 앞 차·사람 앞에서 선다. 경찰 추격이 다가오면 경적을 울리고 급정거해 갓길로 붙는다. 주차 차량은 갓길에 서 있다. 부딪히면 밀리고 파손되며, 부서지면 연기만 나고 **폭발하지 않는다**(도시는 연쇄 폭발을 만들지 않는다). 부서진 차는 그 자리에 남는다. 경찰차는 일반 차량과 부딪혀 피해를 입지만 그것만으로 파괴되지 않는다.
- **연출:** 충돌 시 파티클(나뭇잎·불꽃·쓰레기·먼지), 효과음(부딪힘·쓰러짐·경적), 플레이어가 세게 부딪히면 카메라 흔들림.
- **모바일 성능:** 휴대폰(터치 화면 또는 작은 화면)은 행인 10·주행 차량 6·주차 차량 10(PC는 18·10·16), 렌더 해상도 1.5배 이하, 그림자 맵 1024. 프레임 속도 조절기(`src/main.js`)가 30 FPS 아래로 1.5초 이상 떨어지면 도시 인원을 20%씩 줄이고(최소 40%) 휴대폰은 해상도를 한 단계 낮추며, 여유가 생기면 천천히 되돌린다. 경찰·물리 등 게임 규칙은 바꾸지 않는다. 시설물·행인·차량은 모두 인스턴싱으로 그려 종류별 그리기 1회이고 그림자를 만들지 않는다. 충돌 계산은 격자로 주변만 확인한다(기존 차량-건물 충돌도 같은 결과로 약 2.5배 빨라졌다).

> 실제 iOS Safari·실제 휴대폰에서는 아직 테스트하지 못했습니다(검증은 Chromium의 iPhone 13 화면 흉내, GPU 없음). 실제 기기 30 FPS 여부는 미확인입니다. 자세한 결과는 [TESTING.md](TESTING.md)의 V1.9 섹션.

조정값은 `src/game/city.js`의 `PROPS`(크기·부서지는 속도), `BUDGETS`(기기별 인원)입니다. `new Simulation(layout, { city: true })`로 켜며, 실제 게임은 켜져 있습니다(이전 버전의 고정 시험은 꺼진 상태로 실행).

## V1.8 (이전)

V1.8은 V1.7의 체포·바리케이드·화면 밖 증원·탈출을 그대로 유지하면서 **경찰 압박(측면·전방)**, **실제 다중 충돌과 2~3대 연쇄 폭발 연출**, **영구 잔해(경찰차 본체·파편·화염·연기)**를 강화합니다.

```sh
npm ci
npm run dev
```

Node.js 22.12 이상(또는 20.19 이상). ← / → 또는 A / D로 조향하고 P / Escape로 일시정지합니다. 모바일은 좌우 버튼을 누릅니다. 자동 전진하며 드리프트 버튼은 없습니다. 60초 생존 후 외곽 최종 게이트를 통과하면 `ESCAPED!`와 500 크레딧을 한 번 지급합니다.

## V1.8 변경 내용

- **역할 기반 경찰 압박 (`src/game/police.js`):** 플레이어에 가장 가까운 1대는 후방 추격, 2·3번째는 **좌우 양쪽 측면**에 붙어 조이고(경찰 4대 이상일 때, 2차), 나머지는 전방 차단을 맡습니다. 측면 차는 뒤에서 플레이어보다 빠르게 따라붙은 뒤 옆자리를 유지하며, 모퉁이에서 원래 자리가 막히면 좁은 자리나 반대쪽으로 바꿉니다. 전방 차단차는 위치를 잡을 때만 27.5(+최대 2) 속도로 질주하고, 절반은 A* 경로에 플레이어 주변 감점을 주어 **평행 도로로 돌아 앞/옆 골목에서** 나타납니다. 플레이어 앞에 들어선 차단차는 정면 돌진 대신 **감속하며 도로를 막아** 피할 여지를 줍니다. 플레이어가 느려지거나 갇히면(약 1.2초 평균 이동 속도 13 미만) 모든 경찰이 기존 포위 동작으로 모여 3초 체포가 그대로 작동합니다. 바로 뒤의 추격차는 매초 들이받는 대신 꼬리를 물듯 속도를 맞춥니다.
- **무의미한 자폭 감소, 실제 충돌 유지:** 같은 차선·같은 방향의 경찰은 추돌하지 않고 간격을 유지하거나(후방 추격차) 옆 차선으로 추월합니다(측면·전방 역할). 플레이어와 22 이상 떨어진 곳에서 마주 오거나 교차하는 경찰은 우측으로 비키고 감속합니다. 플레이어 주변에서 다른 방향으로 모여드는 차량의 충돌은 그대로 물리 계산되므로 실제 다중 충돌이 발생합니다. 시간·난수로 폭발시키는 로직은 여전히 없습니다.
- **2~3대 연쇄 폭발 (`simulation.js`):** 연쇄의 각 단계는 0.22초씩 차례로 화면·사운드에 나타납니다(물리·피해·잔해는 같은 시점에 계산). 폭발 에너지는 단계마다 72%로 줄어 이미 손상된 이웃만 연쇄되고, 무리 전체가 한 번에 사라지는 4대 이상 연쇄는 줄었습니다. 뒤 단계 폭발일수록 크게 표시되고, 플레이어 근처 폭발마다 카메라가 흔들립니다(그리기 직전에만 적용되어 증원·가시성 계산에는 영향 없음).
- **영구 잔해 (`src/render/wrecks.js`, `explosions.js`):** 폭발한 경찰차는 공중에서 뒤집혀 지붕으로 떨어지고, **같은 자세의 그을린 경찰차 본체**(경광등·바퀴 포함)가 그대로 남습니다. 바닥 그을음, 붉은 잔불 빛, 5개 불꽃과 6개 연기 기둥, 위로 튀는 불티 4개가 RESTART 전까지 계속 탑니다. 근처에서 새 폭발이 일어나면 기존 잔해의 불길과 연기가 다시 크게 치솟았다가 가라앉습니다(2차). 폭발로 튄 파편 18개는 착지 후 사라지지 않고 InstancedMesh로 옮겨져 **게임 종료까지 도로에 남습니다**(재질당 그리기 1회).

### 도로 봉쇄·운전자 시점 PIP (브랜치 `claude/v18-blockade-pip`)

- **도로 봉쇄 (`src/game/roadblock.js`):** 플레이어가 달리는 도로를 예측해 앞쪽 블록 중간(교차로 제외) 지점을 고르고, 플레이어보다 먼저 도착할 수 있는 경찰 2~3대를 보냅니다(뒤에서 쫓는 1대는 제외). 도착 시간은 격자 도로 거리·출발·코너·정지 시간을 더해 계산하고, 가까운 지점이 불가능하면 더 먼 지점을 찾습니다. 인도까지 포함한 실제 주행 폭을 재서 모든 틈이 플레이어 차보다 좁도록 대수와 간격을 정합니다. 경찰차는 접근 → 감속(정지 거리 계산) → 도로를 가로질러 정차 → 정지 유지(제자리 회전만, 밀리면 천천히 복귀)하며, 정지한 봉쇄 차량은 플레이어가 밀어낼 수 없습니다. 플레이어가 막혀 서면 기존 3초 체포가 그대로 진행되고, 다른 길로 빠지거나 봉쇄에서 18 이상 벗어나거나 지나치면 해제되어 다시 추격합니다. 봉쇄에 붙어 비비는 동안의 방향 변화는 이탈로 보지 않습니다.
- **충돌/연쇄:** 경찰차끼리 강하게(충격 30 이상) 부딪히면 두 대가 한 번에 폭발합니다. 폭발 피해는 90 → 60으로 줄여 멀쩡한 주변 차량은 연쇄 폭발하지 않고 이미 손상된 차량만 이어집니다. 경찰은 정차한 동료(봉쇄·포위 차량)를 들이받지 않고 그 앞에서 감속합니다.
- **운전자 시점 PIP (`src/render/pip.js`):** 기존 탑뷰 위에 보닛 시점 보조 화면을 같은 캔버스에 한 번 더 그립니다(그림자 맵 재사용, 탑뷰용 건물 투명화는 PIP에서 불투명). `PIP` 버튼 또는 `V` 키로 켜고 끄며 선택은 브라우저에 기억됩니다. PC 기본 ON, 휴대폰·터치 화면 기본 OFF. PC는 상단 중앙(HUD 아래, 미션 카드는 그 아래로 이동), 세로 휴대폰은 WANTED 아래 오른쪽, 가로 휴대폰은 로고 아래 왼쪽에 배치해 HUD·조작 버튼과 겹치지 않습니다.

### 경찰 AI 실동작 수정 (브랜치 `claude/v18-police-fix`, 기준 `c09c40a`)

실제 플레이에서 확인된 문제(벽 앞에 선 플레이어 주위를 맴돎, 경찰끼리 세게 부딪혀도 계속 추격, 앞의 경찰차가 플레이어와 같이 달림)를 고쳤습니다. PIP는 바꾸지 않았습니다.

- **실제 포위 (`src/game/cordon.js`):** 플레이어가 거의 멈추면(실제 이동 속도 8 이하) 플레이어 차체 크기로 36방향 "탈출 광선"을 쏴서, 벽·건물·이미 정차한 경찰차에 막히지 않은 방향(실제 빠져나갈 수 있는 방향)만 골라 그 틈을 막을 자리를 계산합니다. 벽에 붙은 경우 열린 호의 양 끝(벽에 바짝)과 그 사이에 차 사이 틈이 플레이어 차 폭보다 좁도록 배치합니다. 경찰차는 가장 급한 자리부터 가까운 차가 맡고, 정지 거리 계산으로 감속해 자리에서 **완전히 정차하고 위치·방향을 유지**합니다(다시 계획해도 자리가 거의 같으면 그대로 유지). 다가오는 동안 서로 양보하고(번호가 낮은 차·정차한 차 우선, 정차한 동료는 비켜 돌아감), 플레이어 근처에서 서로 정면으로 다가오면 급제동해 들이받지 않습니다. 정차한 포위 차량은 밀리지 않습니다.
- **포위 완료 판정:** 기존 차체 탈출 검사(BFS)와 함께, 탈출 광선이 하나라도 열려 있으면 포위 완료가 아닙니다. 열린 틈이 남으면 0.4초마다 그 틈을 실제로 막는 자리를 계산해 가장 가까운 차(남는 차가 없으면 아무것도 막지 않는 포위 차)를 보내고, 닿을 수 없는 자리는 포기하고 다른 차를 보냅니다. 플레이어가 막힌 도로 봉쇄 차량 중 벽 역할이 없는 차도 포위에 씁니다. 모두 정차했는데 틈이 남으면 지금 위치 기준으로 다시 계획합니다(최대 2회).
- **탈출로가 남으면 체포하지 않음:** 직선 36방향 검사에 더해, 차 폭 원을 주변 공간에 퍼뜨려 꺾어서 빠져나가는 길(제자리에서 방향을 틀고 두 차 모서리 사이로 비스듬히)까지 찾는다. 벽은 물리와 같은 반경(1.15 m)으로, 경찰차는 정차(고정)한 포위·봉쇄 차량만 벽으로 센다. 플레이어 옆에 멈춘 경찰차는 그 자리에서 포위에 편입·고정된다. 자연 주행 48판 검사에서 잘못된 체포 8건 → 0건(`scripts/audit-arrests.js`).
- **탈출 시 해제:** 플레이어가 포위 중심에서 9 이상 벗어나거나 14 이상 속도로 0.8초 이상 달리면 하차한 경찰이 차로 돌아간 뒤 정차를 풀고 재추격합니다. 벽에 대고 헛바퀴만 도는 것은 이동으로 보지 않습니다.
- **경찰 하차·체포 (`src/render/officers.js`):** 포위가 완료되고 플레이어가 멈추면 정차한 포위 차 최대 4대에서 경찰 2~4명이 내립니다(차가 1대면 2명). 차 뒤쪽에 서서 플레이어 차량에 총을 겨누는 경찰과 주변을 둘러보는 경찰(사주경계)을 번갈아 배치합니다. 기존 3초 체포 판정이 그대로 진행되고, 확정되면 빨강·파랑 경광 플래시와 함께 BUSTED 화면이 나옵니다. 경찰은 게임과 같은 로우폴리 스타일(남색 제복·모자·배지·양손 권총)입니다.
- **충돌·폭발 (`police.js`, `simulation.js`):** 경찰끼리 충돌은 접근 속도와 상대 속도로 충격량을 계산합니다. 충격 14 이상이면 두 대 모두 파손·폭발(엇갈려 스친 정도는 누적 피해만), 10 이상이면 두 대가 0.8초 멈칫하며 서로 밀어붙인 채 계속 달리지 않습니다. 폭발 충격파는 주변 차를 흔들고 피해를 주지만 **충돌 없이 폭발만으로는 차가 터지지 않습니다**(같은 충돌로 이미 부서진 차만 차례로 터짐). 잔해는 그대로 남습니다.
- **전방 차단 (`roadblock.js`):** 플레이어 앞에서 같은 방향으로 달리는 경찰은 즉시 앞쪽 차단 역할을 맡아, 정지 거리만큼 앞 지점에서 감속해 도로를 가로질러 정차합니다(플레이어보다 앞서 달리는 것이 목적이 아님). 도로 폭을 재서 필요한 대수(2대 이상)를 보내고, 앞쪽에 1대뿐이면 일단 그 차가 막고 나머지는 포위로 합류합니다.

V1.7의 3초 포위 체포, A* 추격·최대 8대 증원, 화면 밖 후방 증원 규칙, 노란 전체 폭 바리케이드/우회로, 플레이어 건물 피해 0과 벽 슬라이딩, 건물 투명화, 먼지·스키드, Web Audio, 음소거·일시정지, 탈출 미션·보상을 유지합니다. 조정값은 `src/game/config.js`의 `frontSprintSpeed`, `blockerApproachSpeed`, `flankSprintSpeed`, `chainStepSeconds`, `chainFalloff`, `frontBlockStart`입니다.

## 검증

```sh
npm test
npx playwright install chromium webkit
npm run test:browser
node scripts/reproduce-v16.js
node scripts/measure-v17.js
node scripts/measure-v18.js            # V1.8 압박·다중 폭발 측정
node scripts/measure-v18.js <V1.7 경로>  # 같은 측정을 V1.7 체크아웃에 실행
npm run build
npm run preview
# 별도 터미널: 프로덕션 실행 확인
node scripts/production-smoke.js
```

`reproduce-v16.js`는 기본 시작 위치에서 처음 5초 직진 후 우회전 입력만 유지합니다. 모바일 브라우저 재현은 START부터 우회전하며, 추가 정상 경로는 `tests/v17.test.js`에서 검증합니다. `measure-v17.js`는 PC/휴대폰 카메라, 6개 시드의 일반·급회전 주행 및 2개 시드 직진 주행에서 자연 충돌·폭발·증원을 기록합니다. 경찰 배치·내구도·최고속도·증원·미션을 변경하지 않고 실제 AI 포위/체포 시간 기록을 출력합니다. 브라우저 검사는 같은 입력을 실제 requestAnimationFrame 게임 루프에서 실행합니다. 별도의 잔해 검사만 충돌 fixture와 고정 60 Hz 진행을 사용합니다.

재현 경로, 실제 화면과 시간 기록, 테스트 결과는 [TESTING.md](TESTING.md)에 있습니다. 과거 버전 수치는 `docs/*-v1.5.json` 등 버전별 파일에 보존합니다. 모바일 WebKit 에뮬레이션은 실제 iPhone 성능 검증을 대체하지 않습니다.

## Cloudflare Pages

프로덕션 브랜치 `main`, 빌드 `npm run build`, 출력 `dist`, Node.js 22. 루트 디렉터리는 저장소 루트입니다. 별도 서버·DB·API 키는 필요하지 않습니다. `wrangler.jsonc`와 정적 응답 헤더를 유지합니다.

Web Audio는 START 사용자 동작 후 활성화되며 기본 ON입니다. 오디오 미지원에서도 게임은 계속됩니다. 외부 음원은 사용하지 않으며 Google Fonts는 선택적 글꼴입니다. 크레딧은 현재 실행의 보상이며 영구 지갑은 후속 확장 대상입니다.
